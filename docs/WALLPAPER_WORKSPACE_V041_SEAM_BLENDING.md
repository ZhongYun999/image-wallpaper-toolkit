# Wallpaper Workspace v0.4.1：接缝融合

v0.4 已经具备自由缩放、自由平移和自动模糊填边，但清晰原图与模糊扩展区之间仍可能出现一条若隐若现的边界。原因不是颜色不连续，而是清晰度在边界处突然跳变。

v0.4.1 新增 **seam blending（接缝融合）**：只在真正与扩展区接壤的原图边缘做一条很窄的透明度过渡带，让清晰图逐渐融入模糊延展区；原图中心区域仍保持完全清晰。

## 参数

`seam_blend_px`：接缝过渡宽度。控制台预设：

- `0 px`：关闭融合；
- `24 px`：很窄，接近旧 iOS 的轻度处理；
- `40 px`：默认推荐起步；
- `64 px`：更稳妥；
- `96 px`：更柔和。

`seam_curve`：过渡曲线，默认 `smoothstep`，也支持 `linear`。

## 处理逻辑

```text
中心主体：完全清晰
        ↓
窄幅过渡带：清晰 → 模糊
        ↓
外围：reflect / edge 延展 + Gaussian Blur
```

融合只会应用在存在扩展区域的边：如果某一边的清晰图片已经超出工作画布，则那一边不会额外羽化。

## 推荐调法

先用 `40 px`。如果仍能看到矩形边界，提高到 `64 px`；如果仍明显，再试 `96 px`。如果觉得主体边缘被软化过多，则降到 `24 px`。

真正影响观感的是 `scale + offset + blur_radius + seam_blend_px` 的组合。建议先确定主体大小和位置，再调接缝宽度，而不是靠增大模糊半径来掩盖边界。
