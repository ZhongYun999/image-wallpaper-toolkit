# Wallpaper Workspace v0.5 - Display Calibration

v0.5 在 v0.4.1 的基础上新增 **显示校准（Display Calibration）**，用于处理这类真实使用差异：

- 电脑 IPS 屏幕上看起来刚好的壁纸；
- 到 iPad Pro OLED 上，暗部 / 中间调显得更亮，颜色也可能更艳。

这里的目标不是“精确模拟 iPad 面板”，而是给最终壁纸增加一组可重复、可量化的输出调整参数。

## 处理顺序

所有校准都发生在 **最终导出前**：

```text
Workspace 构图
    ↓
边缘填充 + 模糊 + 接缝融合
    ↓
亮度 / 对比度 / 饱和度 / Gamma
    ↓
导出 PNG
```

这样清晰主体和模糊延展区会一起接受同一套显示校准，不会产生新的色调断层。

## 四个输出校准参数

### `output_brightness`

整体明暗调整。

- `1.00` = 不调整
- `0.95` = 整体轻微压暗
- `1.05` = 整体轻微提亮

### `output_contrast`

调整整体反差。

- `< 1.00` 会让高光和阴影更接近中间值，观感更柔和；
- `> 1.00` 会增强明暗分离。

因此“暗部看起来偏亮”时，不建议只靠降低 contrast 解决；更适合先用亮度和 Gamma，再根据整体观感决定是否降低对比度。

### `output_saturation`

控制颜色强度。

动漫壁纸里的红色、蓝紫色在 OLED 上尤其容易显得过饱和，可以先试：

```text
95% → 90%
```

### `output_gamma`

主要调整中间调：

- `1.00` = 不调整
- `> 1.00` = 压暗中间调
- `< 1.00` = 提亮中间调

对“电脑上刚好、iPad 上暗部 / 中间调偏亮”的情况，`1.05 ~ 1.10` 通常比单纯继续降低 brightness 更容易保留高光层次。

## v0.5 预设

为了保持兼容，默认选择仍然是 **不调整**：

```text
brightness = 100%
contrast   = 100%
saturation = 100%
gamma      = 1.00
```

另外提供两个快速起点：

### iPad OLED Dark

```text
brightness = 95%
contrast   = 100%
saturation = 95%
gamma      = 1.06
```

适合：暗色动漫壁纸在 OLED 上显得偏亮、偏艳。

### iPad OLED Soft

```text
brightness = 95%
contrast   = 95%
saturation = 92%
gamma      = 1.04
```

适合：除了偏亮 / 偏艳之外，还希望整体反差柔和一些。

## 推荐调参顺序

建议每次只改一个维度，方便和 iPad 实机对比：

1. 先试 `iPad OLED Dark`；
2. 如果仍然偏亮，把 Gamma 从 `1.06` 调到 `1.08` / `1.10`；
3. 如果颜色太艳，把 Saturation 从 `95%` 调到 `90%`；
4. 如果整体反差太硬，再把 Contrast 调到 `95%`；
5. Brightness 最后只做小幅收尾。

## 与 v0.4.1 的兼容性

`WorkspaceOptions` 中新增的四个参数默认全部为中性值，所以直接使用旧代码路径时，输出不会因为升级到 v0.5 自动改变。

同时，根据实际壁纸测试，`seam_blend_px` 默认从 `40 px` 调整为 `64 px`，让模糊延展与清晰原图之间的过渡更接近旧 iOS 自动填充的视觉效果。

## 后续方向

如果继续升级，最值得做的是：

- 实时预览 GUI
- 保存自定义显示预设
- OLED / IPS 对比预览（仅作视觉参考，不宣称精确色彩模拟）
- 记录最近一次参数，减少重复输入
