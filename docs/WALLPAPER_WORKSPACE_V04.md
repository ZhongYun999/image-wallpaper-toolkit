# v0.4 Wallpaper Workspace

v0.4 的目标不是“替用户决定最终壁纸构图”，而是生成一张 **可以在 iPad 壁纸设置界面继续缩放和拖动的高余量母版**。

## 为什么需要 Workspace

实际需求包含两个不同问题：

1. **画质余量**
   - 用户可能在 iPad 中继续放大壁纸；
   - 因此可以先用 Real-ESRGAN 得到更高分辨率母版。

2. **构图余量**
   - 用户希望在 iPad 中继续上下左右拖动；
   - 因此导出的图片本身应该在清晰原图周围拥有额外的、自然的模糊延展区域。

v0.4 把它们明确拆成两步：

```text
低分辨率原图（可选）
        │
        ▼
Real-ESRGAN 超分
        │
        ▼
高分辨率清晰母版
        │
        ▼
Wallpaper Workspace
        │
        ├─ 自由 scale
        ├─ 自由 offset_x
        ├─ 自由 offset_y
        └─ 自动模糊填充暴露区域
        │
        ▼
最终工作母版 PNG
        │
        ▼
iPad 壁纸界面继续缩放 / 平移
```

## scale 的定义

v0.4 不再用 v0.3 的 `focus_x / focus_y` 间接控制裁切。

新的 `scale` 定义为 **相对于 contain fit 的倍率**。

例如原图和画布宽高比相同：

```text
100% = 原图刚好铺满画布
85%  = 原图缩小，四周各留一部分操作余量
120% = 原图放大，允许一部分超出画布
```

对于横图放进竖屏，100% 表示“完整横图全部放进竖屏”，因此上下会产生大量扩展区。用户可以主动把 scale 提高到 120%、150% 或更高，获得更大的主体。

## 位移

```python
offset_x
offset_y
```

都是相对于“居中位置”的像素偏移。

```text
offset_x > 0  向右
offset_x < 0  向左

offset_y > 0  向下
offset_y < 0  向上
```

这与 v0.3 的裁切焦点不同：v0.4 真的把整张清晰图片作为对象移动。

## 自动边缘填充

v0.4 不再要求用户提前指定“顶部扩展 25%”或“左侧扩展 10%”。

程序会根据当前清晰图片在画布中的矩形位置，自动判断哪些区域暴露。

例如：

```text
┌─────────────────────┐
│ 模糊填充             │
│                     │
│    ┌────────────┐   │
│    │  清晰原图   │   │
│    │            │   │
│    └────────────┘   │
│            模糊填充  │
└─────────────────────┘
```

当用户把清晰图片向下移动，上方空出来的区域会自动增加并自动补齐。

## reflect 算法

程序不是把完整原图再放大成一个“模糊背景”。

而是把画布坐标换算成清晰图片的局部坐标，超出边界后用镜像规则折回：

```text
... 3 2 1 | 0 1 2 3 | 2 1 0 ...
            清晰图片
```

然后只把这个自动延展层模糊，再把清晰原图贴回。

这意味着：

- 清晰原图始终是主体；
- 原图移动以后，填充会跟着变化；
- 不会出现 v0.2 的“照片卡片 + 模糊全屏背景”。

## 推荐工作流

如果原图分辨率已经足够高：

```text
主菜单 -> Wallpaper Workspace
```

如果准备在 iPad 中进行较大的二次放大：

```text
主菜单 -> AI 超分
        ↓
超分输出 PNG
        ↓
主菜单 -> Wallpaper Workspace
```

## 推荐的 iPad Pro 13" 母版

### 普通余量

```text
画布：3096×4128（设备 1.5x）
清晰原图：85%
位移：0, 0
blur：96 或 128 px
reflect
```

### 需要明显顶部余量

先用：

```text
scale = 85%
offset_y = +200 ~ +500 px
```

这样清晰主体向下移动，上方会自动补出更多模糊空间。

最终不必在电脑端决定精确取景，真正的最后一步留给 iPad 壁纸编辑界面。
